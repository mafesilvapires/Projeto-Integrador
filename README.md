# Projeto Integrador

Repositório destinado ao desenvolvimento do Projeto Integrador da disciplina.

Neste momento, o projeto encontra-se em **fase inicial de planejamento**, com o tema, requisitos e escopo ainda em processo de definição pelo grupo. Como proposta inicial, está sendo considerada a criação de um **software educativo voltado ao contexto de academias**, com o objetivo de auxiliar usuários na compreensão de conceitos relacionados a treinamento, exercícios e/ou organização de atividades físicas.

A proposta poderá ser ajustada ou substituída conforme a definição dos requisitos do projeto e as necessidades identificadas durante as próximas etapas do desenvolvimento.

## Tecnologias e arquitetura

A definição da stack tecnológica, incluindo linguagem de programação, banco de dados e demais tecnologias, será realizada após a definição do escopo e dos requisitos do projeto.

A arquitetura da aplicação também será estabelecida e documentada no decorrer da etapa de planejamento.

## Documentação

Os documentos relacionados aos requisitos e ao escopo do projeto serão disponibilizados na pasta `docs/` deste repositório.

## Gerenciamento

O desenvolvimento será acompanhado por meio do **GitHub Projects**, utilizando um quadro Kanban para organização das atividades, etapas e responsáveis.

Todos os integrantes do grupo participarão do desenvolvimento e realizarão commits no repositório durante a execução do projeto.
